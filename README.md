# قالب HTML فروشگاه رنگ صادقی

بازنویسی کامل قالب سایت [rangsadeghy.com](https://rangsadeghy.com) به صورت **HTML + CSS + JS** خالص (بدون بیلد و بدون وابستگی خارجی)، ریسپانسیو و راست‌به‌چپ، همراه با طراحی جدید و به‌روز برای بخش وبلاگ.

---

## صفحات آماده

| صفحه | فایل | توضیح |
|---|---|---|
| صفحه اصلی | `index.html` | **طراحی جدید (نسخه ۲):** هدر دوطبقه با مگامنوی تصویری و هدر چسبانِ فشرده‌شو، هیروی اسلایدری + دو بنر کنار، ردیف آیکونی دسته‌بندی‌ها، «پیشنهاد شگفت‌انگیز» با شمارش معکوس، نوار خدمات، «خرید بر اساس پروژه»، ریل‌های پرفروش/جدید، برندها، پالت رنگ، مجله، کارت فروشگاه و خبرنامه و فوتر جدید |
| فروشگاه | `shop.html` | لیست محصولات با فیلتر دسته‌بندی، برند، محدوده قیمت، تخفیف و موجودی + مرتب‌سازی، نمایش شبکه‌ای/لیستی و صفحه‌بندی |
| دسته بندی محصولات | `categories.html` | صفحه دایرکتوری ۵ دسته اصلی با تصویر، توضیح، تعداد کالا و لینک زیرشاخه‌ها |
| تک صفحه محصول | `product.html` | گالری تصاویر، انتخاب وزن/رنگ، تعداد، افزودن به سبد، تب‌های توضیحات/مشخصات/نظرات/ارسال، محصولات مرتبط و نوار خرید چسبان موبایل |
| وبلاگ | `blog.html` | **طراحی جدید:** مقاله ویژه، فیلتر دسته‌بندی، جستجوی زنده، کارت‌های پست، ستون کنار (پرخوانده‌ترین‌ها، برچسب‌ها، CTA) و خبرنامه |
| تک صفحه نوشته | `blog-single.html` | **طراحی جدید:** نوار پیشرفت مطالعه، فهرست مطالب چسبان با هایلایت خودکار، تیپوگرافی مقاله، جدول، نقل‌قول، باکس نکته، نویسنده، اشتراک‌گذاری و پست‌های مرتبط |
| درباره ما | `about.html` | متن و اطلاعات واقعی صفحه «درباره ما» سایت اصلی + آمار، داستان، ارزش‌ها، گالری و برندها |
| تماس با ما | `contact.html` | آدرس، ساعت کاری، تلفن و ایمیل واقعی + فرم اعتبارسنجی‌شده، نقشه، پرسش‌های پرتکرار |
| فروشگاه های ما | `stores.html` | دو فروشگاه مجموعه: `rangsadeghy.com` و `naghshinoart.com` با مقایسه و نقشه |
| سبد خرید | `cart.html` | صفحه کامل سبد خرید: مراحل تسویه، لیست کالا با تغییر تعداد/حذف، نوار ارسال رایگان، کد تخفیف، خلاصه سفارش، محصولات پیشنهادی و نوار پرداخت چسبان موبایل |
| تسویه حساب | `checkout.html` | **چندمرحله‌ای:** آدرس تحویل (انتخاب/ثبت آدرس جدید با اعتبارسنجی، گیرنده) ← شیوه ارسال (پیک آمل، پست، تیپاکس، تحویل حضوری + انتخاب روز و بازه زمانی) ← پرداخت (درگاه، پرداخت در محل، کارت به کارت، کیف پول، کد تخفیف، بازبینی نهایی و پذیرش قوانین) ← صفحه تکمیل سفارش با کد پیگیری |
| جزئیات سفارش | `order-details.html` | **مشابه دیجی‌کالا:** سربرگ سفارش (کد، تاریخ، وضعیت، مبلغ)، رهگیری مرسوله با ۵ مرحله و کد رهگیری، اطلاعات ارسال و پرداخت، اقلام سفارش با اکشن‌های هر کالا، فاکتور خرید قابل چاپ با جدول و جمع‌بندی، گردش سفارش، خلاصه پرداخت، پشتیبانی سفارش و لغو/مرجوعی |
| حساب کاربری | `account.html` | پنل کاربری الهام‌گرفته از دیجی‌کالا: هدر کاربر، کارت‌های خلاصه، پیگیری سفارش، سفارش‌ها، آدرس‌ها، علاقه‌مندی‌ها، کیف پول و کد تخفیف، اطلاعات حساب و پشتیبانی |

## فایل‌ها

```
index.html          صفحه اصلی (نسخه قبلی + لینک‌های به‌روزشده + استایل جدید)
shop.html           فروشگاه
categories.html     دسته بندی محصولات
product.html        تک صفحه محصول
blog.html           وبلاگ
blog-single.html    تک صفحه نوشته
about.html          درباره ما
contact.html        تماس با ما
stores.html         فروشگاه های ما
cart.html           سبد خرید
checkout.html       تسویه حساب چندمرحله‌ای
account.html        حساب کاربری

styles.css          استایل پایه سایت (هدر، فوتر، کارت محصول، سبد، مودال‌ها)
home.css            استایل اختصاصی صفحه اصلی جدید (فقط در index.html بارگذاری می‌شود)
pages.css           استایل و کامپوننت‌های صفحات داخلی (فیلتر، گالری، مقاله، فرم...)
app.js              هسته مشترک: دیتای ۳۲ محصول، سبد خرید، علاقه‌مندی، جستجو، منو، مودال
pages.js            منطق اختصاصی هر صفحه (فیلتر فروشگاه، گالری محصول، فیلتر وبلاگ، TOC مقاله، فرم‌ها)
build.py            سازنده صفحات: هدر/فوتر/منوها یک‌بار تعریف شده و صفحات از آن ساخته می‌شوند
assets/fonts        فونت‌های IRANYekanX و Vazirmatn (لوکال)
assets/images       تصاویر محصولات، بنرها و تصاویر شاخص وبلاگ (assets/images/blog)
```

## اجرا

کافی است فایل‌ها را روی هر وب‌سروری سرو کنید (به دلیل استفاده از فونت‌های لوکال و مسیرهای نسبی):

```bash
python3 -m http.server 8000
# سپس http://localhost:8000/index.html
```

برای بازسازی صفحات بعد از تغییر در `build.py`:

```bash
python3 build.py
```

## ویژگی‌های فنی

- **بدون فریم‌ورک**: فقط HTML، CSS و JavaScript خالص؛ بدون jQuery، بدون CDN و بدون درخواست خارجی.
- **ریسپانسیو**: سه بریک‌پوینت اصلی (۱۲۰۰ / ۱۰۲۴ / ۷۶۸ و ۴۲۰ پیکسل)؛ هدر و نوار ابزار مخصوص موبایل، فیلترهای بازشو، نوار خرید چسبان.
- **هدر چسبان هوشمند (دسکتاپ)**: `main-header` بعد از عبور از نوار لوگو بدون پرش می‌چسبد و با ادامه اسکرول به پایین، ارتفاعش با انیمیشن نرم از ۸۵ به ۶۲ پیکسل کم می‌شود (دکمه دسته‌بندی، جستجو و آیکون‌ها هم کوچک می‌شوند، پس‌زمینه شیشه‌ای). ستون‌های چسبان صفحات با متغیر `--sticky-offset` هماهنگ می‌شوند. احترام به `prefers-reduced-motion`.
- **تسویه حساب**: وضعیت هر مرحله در `sessionStorage` حفظ می‌شود، دکمه Back مرورگر بین مراحل جابه‌جا می‌شود، کد تخفیف سبد خرید به تسویه منتقل می‌شود و سفارش ثبت‌شده در تب «سفارش‌های من» حساب کاربری (`account.html#orders`) نمایش داده می‌شود.
- **منوی ثابت پایین در موبایل** (`≤۱۰۲۴px`): خانه، فروشگاه، منو، سبد خرید و حساب کاربری؛ با بزرگ‌نمایی سبد، حالت فعال (`aria-current`) و احترام به `env(safe-area-inset-bottom)`.
- **استانداردهای موبایل (Google / Material)**: تمام دکمه‌ها و لینک‌های تعاملی حداقل ۴۴–۴۸ پیکسل، فونت ورودی‌ها ۱۶ پیکسل (جلوگیری از زوم iOS)، `viewport` با `maximum-scale` باز، بدون اسکرول افقی در ۳۶۰/۳۹۰/۷۶۸/۱۴۴۰ پیکسل.
- **سبد خرید دو حالت**: در دسکتاپ دکمه سبد خرید مستقیماً `cart.html` را باز می‌کند و در موبایل کیسه بالای صفحه کشوی سبد را نشان می‌دهد؛ دکمه پرداخت کشو هم به `cart.html` می‌رود.
- **سبد خرید کامل**: تغییر تعداد، حذف، ذخیره در علاقه‌مندی، خالی‌کردن سبد، کدهای تخفیف (`RANG15` = ۱۵٪ و `PATINA10` = ۱۰٪)، نوار «ارسال رایگان» (آستانه ۱۰ میلیون تومان)، محاسبه تخفیف/هزینه ارسال/مبلغ نهایی و محصولات پیشنهادی بر اساس سبد.
- **حساب کاربری**: تب‌بندی بدون رفرش (`overview / orders / addresses / favorites / wallet / profile / support`)، پیگیری سفارش چهارمرحله‌ای، سفارش‌های نمونه با وضعیت، آدرس پیش‌فرض، علاقه‌مندی‌های واقعی از `localStorage`، کیف پول و کارت هدیه، کدهای تخفیف و فرم‌های نمایشی با پیام Toast.
- **RTL کامل** با فونت‌های IRANYekanX و Vazirmatn.
- **دیتای مشترک محصولات** در `app.js`: تمام کارت‌ها، جستجوی سراسری، صفحه محصول (`product.html?id=p10`) و سبد خرید از یک منبع داده می‌خوانند.
- **سبد خرید و علاقه‌مندی واقعی** روی `localStorage` (افزودن، کم/زیاد کردن، حذف، جمع سبد) و مودال ورود.
- **دسترس‌پذیری**: `aria-label`، `aria-expanded`، skip-link، ساختار هدینگ منظم، فوکوس روی مودال‌ها، احترام به `prefers-reduced-motion`.
- **سئو**: تگ‌های `title` و `description` اختصاصی هر صفحه، ساختار معنایی و بردکرامب.
- **جزئیات سفارش کامل**: صفحه `order-details.html` از کد سفارش (`?id=RS-…`) یا آخرین سفارش ثبت‌شده در مرورگر پر می‌شود؛ همه مبالغ، اقلام و فاکتور به‌صورت زنده محاسبه می‌شوند، فاکتور با `@media print` آماده چاپ/PDF است و دکمه‌های کپی کد، لغو سفارش و مرجوعی فعال‌اند.
- **بدون دکمه «خرید سریع و تسویه حساب»**: در صفحه محصول حذف شده و مسیر خرید از «افزودن به سبد» → سبد خرید → تسویه طی می‌شود.

## هدر و فوتر یکسان در همه صفحات (نسخه ۲.۱)

هدر و فوتر جدید صفحه اصلی روی **همه ۱۳ صفحه** اعمال شد (توسط `build.py` تولید می‌شوند، پس در بازسازی‌های بعدی هم حفظ می‌شود):

- `home.css` در همه صفحات بارگذاری می‌شود و کلاس `hx-page` به `body` اضافه شده است (هم‌رنگ شدن پس‌زمینه با صفحه اصلی).
- منوی اصلی در هر صفحه آیتم فعال خودش را دارد (خط زیر کلمه با رنگ اصلی).
- نوار پایین موبایل (خانه/فروشگاه/منو/سبد خرید/حساب کاربری) و دراورهای موبایل در همه صفحات فعال است.
- صفحات داخلی: `body[data-page]` رنگ پس‌زمینه‌ی کرم `#f6f4f1` را از هدر جدید می‌گیرد.

## کارت محصول و اعداد فارسی (نسخه ۲.۱)

- **قاب کارت محصول**: `border:1px solid #e6e6e8` + `border-radius:8px` + سایه‌ی ملایم در هاور (استایل استاندارد دیجی‌کالا).
- **حذف امتیاز ستاره‌ای** از کارت‌ها و کاهش فاصله‌ی قیمت تا دسته‌بندی (کارت‌های صفحه اصلی از ۳۱۸px به ~۲۶۷px فشرده شدند).
- **برچسب تخفیف**: از دایره به مستطیل گوشه‌گرد تغییر کرد، علامت منفی حذف شد و با هاور عبارت «فروش ویژه» نمایش داده می‌شود (`۳۴٪` ← `فروش ویژه ۳۴٪`).
- **اعداد و قیمت‌ها فارسی**: `formatPrice` و کد کالا و عنوان محصولات با ارقام فارسی نمایش داده می‌شوند؛ جستجو با هر دو نوع رقم کار می‌کند و فیلتر قیمت هم ارقام فارسی را می‌پذیرد (`toEn`).
- **هاور منو**: از پس‌زمینه‌ی مستطیلی به خط زیر کلمات با رنگ اصلی (قرمز برند) تغییر کرد.

## صفحه اصلی (نسخه ۲)

صفحه اصلی با الهام از دیجی‌کالا و بنچمارک ۲۰ فروشگاه غیرفارسی (رنگ/ابزار و فروشگاه‌های بزرگ) بازطراحی شد؛ گزارش کامل تحلیل و تصمیم‌ها در `design-notes.md` آمده است. نکات کلیدی:

- **هدر دوطبقه چسبان**: نوار خدمات + نوار اصلی (لوگو، دسته‌بندی، جستجو، ورود، سبد) + ریل منو؛ با اسکرول می‌چسبد و ارتفاعش با انیمیشن کم می‌شود.
- **مگامنوی ساختارمند** با ۴ ستون دسته‌بندی و باکس «پیشنهاد هفته».
- **پیشنهاد شگفت‌انگیز** با شمارش معکوس زنده تا پایان روز و ریل افقی محصول.
- **«خرید بر اساس پروژه» و «پالت رنگ»**: الگوی رایج فروشگاه‌های رنگ (Shop by Project / Color Selector).
- **موبایل**: نوار پایین ثابت پنج‌گانه (خانه، فروشگاه، منو، سبد خرید، حساب کاربری)، ریل‌های اسنپ‌دار و اهداف لمسی ≥۴۴px.

## مخزن گیت‌هاب و انتشار

مخزن: [github.com/amolnovin/rangesadeghi-theme](https://github.com/amolnovin/rangesadeghi-theme) (شاخه‌ی `main`)

```bash
git clone https://github.com/amolnovin/rangesadeghi-theme.git
cd rangesadeghi-theme
python3 -m http.server 8000
```

قالب کاملاً استاتیک است، پس روی **GitHub Pages** هم بدون هیچ تنظیم اضافه‌ای اجرا می‌شود:

1. در مخزن: `Settings → Pages`
2. در بخش *Build and deployment* گزینه‌ی **Deploy from a branch** را انتخاب کنید.
3. شاخه‌ی `main` و پوشه‌ی `/ (root)` را بزنید و Save.
4. آدرس نهایی: `https://amolnovin.github.io/rangesadeghi-theme/`

نکته: فایل`.nojekyll` از قبل در ریشه قرار داده شده تا صفحات بدون پردازش Jekyll سرو شوند.
